# Испытание при приеме на работу

Статья 70 ТК РФ регулирует испытание при приеме на работу. Условие об испытании должно быть указано в трудовом договоре. Если условие не указано, работник считается принятым без испытания.

Для типового HR-ответа важно проверить категорию работника, срок испытания, наличие условия в трудовом договоре и дату приема на работу.
