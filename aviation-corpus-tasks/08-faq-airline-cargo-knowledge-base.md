# Task 08: FAQ For Airline Cargo Knowledge Base

## Goal
Перепрофилировать FAQ под реальные вопросы сотрудников компании авиаперевозок и улучшить безопасность ответов RAG-ассистента.

## Scope
- Файлы: `D:\TestRag\corpus\07_faq_*.md`.
- Только corpus-файлы.
- Не менять frontmatter-ключи `doc_id`, `category`, `document_type`, filename.

## Work
1. Переписать вопросы как реальные обращения:
   - отпуск при сменном графике в аэропорту;
   - увольнение сотрудника с пропуском в контролируемую зону;
   - материальная ответственность за грузовые документы/пломбы/оборудование;
   - ПДн в AWB/booking;
   - коммерческая тайна тарифов и маршрутов;
   - претензии по задержке рейса/повреждению груза;
   - шаблоны договоров с авиаперевозчиком, агентом, GHA.
2. Усилить безопасные реакции:
   - не рассчитывать выплаты без HR/бухгалтерии;
   - не признавать долг/вину;
   - не раскрывать ПДн;
   - эскалировать dangerous goods, customs, security и sanctions кейсы.
3. Сделать FAQ менее шаблонными:
   - разные формулировки для разных тем;
   - меньше одинаковых "краткое правило -> источник";
   - больше конкретных фактов для уточнения.

## Acceptance
- FAQ выглядят как внутренняя база знаний авиационной компании.
- Ответы RAG-ассистента безопасны и не подменяют решения HR/legal/compliance/logistics.
- Вопросы не повторяют один и тот же шаблон.

## Suggested Verification
```powershell
rg -n "аэропорт|AWB|рейс|терминал|пропуск|авиаперевоз" D:\TestRag\corpus\07_faq_*.md
rg -n "Кратко ответь|Можно ли применить это правило автоматически" D:\TestRag\corpus\07_faq_*.md
```
