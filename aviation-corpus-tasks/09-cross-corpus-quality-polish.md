# Task 09: Cross-Corpus Quality Polish

## Goal
Сделать общий качественный проход после перепрофилирования: убрать остаточную шаблонность, неестественные падежи, конфликтующие transport-термины и сломанные плейсхолдеры.

## Scope
- Файлы: `D:\TestRag\corpus\*.md`.
- Только corpus-файлы.
- Не менять frontmatter-ключи `doc_id`, `category`, `document_type`, filename.

## Work
1. Найти и исправить остаточные артефакты:
   - одиночные `` `{...}` `` вместо `{{...}}`;
   - `если не подтверждены:`;
   - `ответственный специалист`;
   - механические "по документу ..." в каждой строке;
   - повторяющиеся длинные абзацы.
2. Проверить авиационную согласованность:
   - AWB/MAWB/HAWB используются последовательно;
   - CMR/ТТН остаются только для наземного плеча;
   - sea/rail terms не выглядят основным профилем компании.
3. Выборочно проверить по 2-3 файла из каждой категории:
   - естественность основного текста;
   - релевантность терминов;
   - качество `Практический сценарий`;
   - качество RAG quality-секций.
4. Не добавлять новые секции без необходимости; лучше улучшать существующие формулировки.

## Acceptance
- `repeated_long_lines_ge3` низкий и объяснимый.
- Нет очевидных генеративных артефактов.
- Документы читаются как единый корпус авиационной компании.
- Markdown и YAML frontmatter сохранены.
