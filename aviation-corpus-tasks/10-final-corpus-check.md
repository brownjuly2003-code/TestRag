# Task 10: Final Corpus Check

## Goal
Проверить итог перепрофилирования и улучшения качества корпуса после всех сессий.

## Scope
- Read-only проверка всего `D:\TestRag\corpus`.
- Не править документы в этой задаче, кроме если явно обнаружен маленький блокер и пользователь разрешил исправление.
- Не менять манифесты, код, README, docs, docker-compose, тесты, конфиги.

## Work
1. Проверить структурные инварианты:
   - `manifest_targets=200`;
   - `corpus_files=200`;
   - `missing=0`;
   - `extra=0`;
   - `missing_sections=0`;
   - `frontmatter_issues=0`;
   - `protected_issues=0`;
   - `broken_corpus_refs=0`.
2. Проверить авиационный профиль:
   - во всех категориях присутствует авиационная предметность;
   - road/rail/sea terms не доминируют;
   - AWB/MAWB/HAWB, airport, flight, handling, terminal, customs, dangerous goods используются осмысленно.
3. Проверить качество текста:
   - повторяющиеся длинные строки;
   - одинаковые секции;
   - неестественные падежи;
   - сломанные `{{...}}`;
   - generic phrases.
4. Запустить тесты.
5. Дать итоговую оценку по 10-балльной шкале:
   - структурная валидность;
   - RAG-пригодность;
   - авиационная доменность;
   - естественность внутренних документов;
   - остаточная шаблонность;
   - готовность демо-корпуса.

## Acceptance
- Все структурные проверки зеленые.
- `python -m pytest` проходит или причина падения точно зафиксирована и не относится к corpus.
- `git status --short --untracked-files=all` содержит только ожидаемые изменения.
- Пользователь получает краткий отчет с метриками и новой оценкой качества.

## Suggested Verification
```powershell
python -m pytest
git -C D:\TestRag status --short --untracked-files=all
```
