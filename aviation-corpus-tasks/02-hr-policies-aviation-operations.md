# Task 02: HR Policies For Aviation Operations

## Goal
Перепрофилировать HR policies/procedures под компанию авиаперевозок и одновременно улучшить качество основных разделов.

## Scope
- Файлы: `D:\TestRag\corpus\01_hr_*.md`.
- Только corpus-файлы.
- Не менять frontmatter-ключи `doc_id`, `category`, `document_type`, filename.

## Work
1. В `Назначение`, `Область применения`, `Порядок действий` добавить авиационный контекст:
   - смены в аэропорту;
   - доступ в контролируемые зоны;
   - сотрудники грузового терминала, логисты авиаперевозок, диспетчеры, специалисты авиационной безопасности;
   - обучение по aviation security, dangerous goods awareness, охране труда на терминале.
2. Усилить HR-сроки и доказательства:
   - график смен, табель, допуск, пропуск, медосмотр, инструктаж, журнал смены, HRIS.
3. Уточнить исключения:
   - отзыв допуска;
   - работа в ночную смену;
   - беременность/медицинские ограничения;
   - дисциплинарное событие в контролируемой зоне;
   - нарушение aviation security.
4. Убрать общие фразы, которые звучат как офисная HR-политика без авиационного контекста.
5. Не ухудшать RAG quality-секции; при необходимости привести их к авиационным доказательствам.

## Acceptance
- HR-документы читаются как документы работодателя в авиагрузовой/аэропортовой среде.
- В документах есть роли, сроки, доказательства и эскалации, связанные с авиаперевозками.
- Нет механической замены всех логистических терминов без смысла.
