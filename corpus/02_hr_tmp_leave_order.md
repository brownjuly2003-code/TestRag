# Приказ об отпуске (шаблон)

## Назначение

Настоящий документ является шаблоном приказа о предоставлении отпуска (форма Т-6 / Т-6а), используемым в ООО «Демо-Логистика» для оформления ежегодного, учебного, декретного, отпуска без сохранения заработной платы и иных видов отпусков.

## Область применения

Шаблон применяется при оформлении всех видов отпусков, предусмотренных Трудовым кодексом РФ и локальными нормативными актами компании. Для каждого вида отпуска используются соответствующие формулировки и основания.

## Термины

- **Приказ об отпуске** — распорядительный документ, оформляющий предоставление отпуска работнику.
- **Форма Т-6** — унифицированная форма приказа об отпуске одного сотрудника.
- **Форма Т-6а** — унифицированная форма приказа об отпуске группы сотрудников.
- **Рабочий год** — период, за который предоставляется ежегодный оплачиваемый отпуск (12 месяцев непрерывной работы).
- **Отпускные** — выплата заработной платы за дни отпуска, рассчитываемая не позднее чем за 3 дня до его начала.

## Порядок действий

### 1. Основания для оформления

HR-специалист оформляет приказ на основании:
- заявления сотрудника (для ежегодного отпуска — не позднее чем за 2 недели до начала);
- графика отпусков (для планового ежегодного отпуска);
- листка нетрудоспособности (для декретного отпуска);
- иных документов, предусмотренных законодательством.

### 2. Текст шаблона

```
                                ПРИКАЗ

г. {{city}}                                    № {{order_number}} от {{order_date}}

О предоставлении отпуска

На основании:
- заявления {{employee_full_name}} от {{request_date}};
- графика отпусков на {{vacation_year}} год.

ПРИКАЗЫВАЮ:

1. Предоставить {{employee_full_name}}, {{position}}, {{department}},
   {{leave_type}} продолжительностью {{days_count}} календарных дней
   с {{start_date}} по {{end_date}}.

2. Выплатить отпускные в размере {{vacation_pay_amount}} руб.
   не позднее {{vacation_pay_deadline}}.

3. За период работы с {{work_period_start}} по {{work_period_end}}
   отпуск предоставляется за {{work_period_years}} рабочий(их) год(а).

4. Основание: заявление от {{request_date}}, график отпусков.

5. С приказом ознакомлен: _________________ / {{employee_full_name}} / {{acknowledgement_date}}

Руководитель кадровой службы _________________ / {{hr_manager_name}}
```

### 3. Виды отпусков и особенности оформления

| Вид отпуска | Основание | Особенности |
|-------------|-----------|-------------|
| Ежегодный основной | График отпусков + заявление | Расчет отпускных за 3 дня до начала |
| Ежегодный дополнительный | График + заявление | Указывается основание (вредные условия, ненормированный день) |
| Учебный | Справка-вызов из учебного заведения | Оплачиваемый / неоплачиваемый в зависимости от формы обучения |
| Декретный | Листок нетрудоспособности | Указывается номер и дата больничного |
| По уходу за ребенком | Заявление + свидетельство о рождении | До 3 лет, пособие до 1.5 лет |
| Без сохранения ЗП | Заявление | Не более {{unpaid_leave_max_days}} дней в год (по соглашению) |

### 4. Согласование и подписание

Приказ согласовывается с руководителем подразделения для обеспечения замещения и утверждается генеральным директором или уполномоченным лицом. Сотрудник ознакамливается с приказом под роспись не позднее чем за 3 рабочих дня до начала отпуска.

### 5. Действия после подписания

- Бухгалтерия рассчитывает и выплачивает отпускные.
- В табеле учета рабочего времени проставляется код «ОТ» (отпуск).
- При переносе отпуска по соглашению сторон оформляется новый приказ, предыдущий аннулируется.

## Правила ответа RAG-ассистента

- Использовать документ как кадровый шаблон, а не как подтверждение уже оформленного кадрового действия.
- Перед черновиком проверить обязательные поля, основание оформления, дату события и полномочия подписанта.
- Не подставлять ФИО, паспортные данные, суммы, даты, должности или основания по догадке.
- Если не хватает данных, вернуть список недостающих полей вместо полного черновика.

## Доказательства и источники для ответа

- заявление сотрудника, приказ, трудовой договор или дополнительное соглашение;
- локальный HR-регламент, график, штатное расписание или табель;
- подтверждение согласования руководителем и HR-владельцем процесса;
- дата события и версия шаблона, действующая на эту дату.

## Ответственные роли

| Роль | Обязанности |
|------|-------------|
| HR-специалист | Прием заявления, оформление приказа, ведение графика отпусков |
| Руководитель подразделения | Согласование отпуска, обеспечение замещения |
| Бухгалтер | Расчет отпускных, выплата в срок |
| Сотрудник | Подача заявления, подпись о ознакомлении |

## Риски и ограничения

- Невыплата отпускных за 3 дня до начала влечет обязанность перенести отпуск по инициативе работника.
- Предоставление отпуска без приказа затрудняет доказывание правомерности отсутствия.
- Перенос отпуска без согласия сотрудника возможен только в исключительных случаях (ст. 124 ТК РФ).
- При увольнении неиспользованный отпуск компенсируется денежной выплатой (ст. 127 ТК РФ).

- основание оформления связано с локальным актом или заявлением;
- даты, должности и суммы не подставлены по догадке.
